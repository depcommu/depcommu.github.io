常见问题

我的数据安全吗？

所有数据存储在浏览器的 localStorage 中，完全在本地处理，不会上传到任何服务器。建议定期使用 ZIP 导出 功能备份数据。

如何在不同设备间同步数据？

目前不支持自动云同步。你可以：
1. 使用文档管理器的 ZIP 导出 功能
2. 在另一台设备上使用 ZIP 导入 功能
3. ZIP 文件包含所有草稿、文件夹和设置

支持哪些 Markdown 扩展语法？

完整支持 GFM（GitHub Flavored Markdown），包括表格、任务列表、围栏代码块（语法高亮）、KaTeX 数学公式、Mermaid 图表（流程图、时序图、甘特图、类图等）、脚注、GFM 警告框等。

如何恢复误删的文档？

如果你之前导出了 ZIP 备份，可以通过 导入 功能恢复。如果没有备份，已删除的本地数据无法恢复。建议定期导出备份。

一键优化功能是什么？

一键优化是基于纯规则算法的 Markdown 格式优化引擎，支持 20+ 优化规则，包括：格式规范化、结构优化、中英排版、语法检测、精简清理。100% 本地运行，不依赖 AI 或网络。

如何更改界面语言？

在设置中心的「行为」标签页中，找到「语言与地区」选项，可选择简体中文、English、日本語、Español、Français 五种语言。

🎨 皮肤自定义开发指南

通过编写 JSON 皮肤文件，你可以完全自定义应用程序的视觉风格。以下是完整的开发指南。

📁 皮肤文件结构

皮肤文件是一个 .json 文件，包含以下必需字段：

{
  "name": "我的自定义皮肤",
  "version": "1.0",
  "author": "你的名字",
  "description": "皮肤描述",
  "variables": {
    "--bg": "#ffffff",
    "--text": "#333333",
    "--accent": "#4a90d9",
    ...更多变量
  }
}

必需变量（至少需包含以下5个）：

--bg、--text、--accent、--border、--bg-secondary
🎨 完整 CSS 变量列表（42个）

基础颜色：--bg --bg-secondary --bg-tertiary --text --text-secondary --text-muted

边框与强调：--border --border-light --accent --accent-hover --accent-light

状态颜色：--danger --warning --success

阴影：--shadow --shadow-lg --radius --radius-sm --transition

工具栏：--toolbar-bg --toolbar-border --capsule-bg --capsule-border

编辑器：--editor-bg --editor-text --editor-gutter-bg --editor-gutter-text --editor-active-line --editor-selection

预览：--preview-bg --preview-text

面板：--status-bg --outline-bg --modal-overlay

滚动条：--scrollbar-thumb --scrollbar-track

代码块：--code-bg --table-stripe

引用：--blockquote-border --blockquote-bg

玻璃效果：--glass-bg --glass-border

字体（可选）：--font-ui --font-editor --font-preview

📝 创建皮肤步骤

步骤 1：创建一个新的 .json 文件

步骤 2：参考上面的文件结构，填写 name、description 等元数据

步骤 3：在 variables 对象中定义所有需要的 CSS 变量

步骤 4：确保至少包含 5 个必需变量

步骤 5：在设置中心 → 皮肤设置 → 上传皮肤文件

步骤 6：系统会自动验证文件格式，验证通过后点击「应用此皮肤」

💡 设计建议与最佳实践

亮色皮肤：使用浅色背景（#f8f9fa 到 #ffffff），深色文字（#222 到 #444），柔和的强调色

暗色皮肤：使用深色背景（#1a1a2e 到 #0d1117），浅色文字（#c9d1d9 到 #e4e4e7），高对比度强调色

对比度：确保文字与背景的对比度 ≥ 4.5:1（WCAG AA 标准）

一致性：保持 --bg、--bg-secondary、--bg-tertiary 的层次递进关系

测试：应用后检查工具栏、编辑器、预览区、设置中心、文件管理器等所有界面元素

🧪 测试与调试

1. 上传皮肤文件后，先点击「应用此皮肤」预览效果

2. 检查所有界面组件：工具栏、编辑器、预览区、大纲、状态栏、文件管理器

3. 切换不同视图模式（双栏/纯编辑/纯预览）确认兼容性

4. 如有问题，可在设置中心 → 外观 → 切换到预设主题进行恢复

5. 使用浏览器开发者工具（F12）检查 CSS 变量是否正确应用
